PYTHON EXCERPTEVIDENCE INTEGRITY

Checking a SHA-256 manifest

A short excerpt from the laboratory’s evidence verifier. It checks file paths and compares a computed digest with the manifest entry.

        path = (ROOT / relpath).resolve()
        if ROOT not in path.parents or not path.is_file():
            print(f"FAIL missing/invalid path: {relpath}")
            failures += 1
            continue
        actual = hashlib.sha256(path.read_bytes()).hexdigest()
        match = actual.lower() == expected.lower()
        print(f"{'PASS' if match else 'FAIL'} {relpath}")
        failures += not match

This excerpt belongs inside the full script. Its checks apply to files covered by that laboratory’s manifest; they do not prove an investigation narrative.
